    Case 1 · Your explanation

    Underfitting

    The model is too restricted to capture an important pattern. Training and test errors are both relatively high.

    Overfitting

    Extra flexibility captures details specific to the training sample. Training error is low, but new-data performance is worse than for a simpler model.

    Wrap-up: what should you take away?
    1. Explain why the model with the lowest training error is not necessarily the most useful.
    2. Does every increase in complexity hurt test performance? Cite an example from the lab.
    3. Does the same complexity setting work best for every pattern and training sample?
    4. Compare the simplest and most flexible models across training samples. Which changes more?

    A gap between training and test error is a clue, not a complete diagnosis. Compare models and look for evidence that flexibility fits sample-specific noise.

    About the data, models, and test set

    All examples are simulated. Training and test points are separate draws from the same process. Within each case, the test set stays fixed while you cycle through three independent training samples. The model never uses test labels during fitting.

    The curved trend uses polynomial regression (degree 0–16). The wave uses Fourier regression (0–18 harmonics). Both use noisy numerical observations, and a tiny fixed ridge term for numerical stability. The two-group case uses decision trees (maximum depth 0–12). The circle uses k-nearest neighbors (99 down to 1 neighbor). Classification labels include 8% random flips. Fewer neighbors make that classifier more local and flexible.

    Regression error is root mean squared error (RMSE), in the units of the vertical axis. Classification error is the percentage of wrong labels. These scores cannot be compared across different cases as a measure of overall model quality.

    The dashed underlying regression curve is the noise-free mean, not a curve that should pass through every point. For the interlocking groups, the reference lines are the two noise-free group centers, not an exact decision boundary. For the circle, the reference line is the noise-free category boundary. Even an appropriate model cannot predict every random deviation.

    Why can we keep looking at test scores? This lab deliberately reveals them to demonstrate generalization. Once you use these scores to choose a setting, these examples function as validation data. In a real project, tune with a validation set and reserve a separate, untouched test set for final evaluation.

    Every setting contains predictions from an actually fitted model, calculated in advance so the lab works offline. The plots do not use hand-drawn error curves. Error scores use all test points. Decision-region displays use a 65 × 65 grid. Curves are clipped to a fixed visible vertical range to keep comparisons readable; any off-plot predictions are reported.
