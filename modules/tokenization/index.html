Tokens and subwords

What Counts as a Word?

Compare boundary decisions, then watch frequent character sequences become subwords.

1 Find boundaries 2 Compare rules 3 Build subwords 4 Stress-test
Learning objectives
  • Explain why a token is a modeling choice.
  • Compare rule-based tokenization strategies.
  • Describe how repeated-pair merging creates subwords.
  • Identify assumptions that fail across writing systems.
Step 1

Find the boundaries

A space is evidence for a boundary, but it is not a universal definition of a word.

Before running the comparison

How many tokens should this text contain? Identify one boundary that a computer could reasonably handle in more than one way.

Step 2

Compare three rules

The same visible text becomes three different datasets.

Which output is correct?

No output is universally correct. A useful tokenizer preserves distinctions needed for a particular analysis while remaining consistent.

Notice: Changing tokenization also changes frequency counts, vocabulary size, and every model trained from those observations.

Build a subword vocabulary
