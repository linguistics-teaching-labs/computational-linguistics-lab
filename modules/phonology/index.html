Phonology

From Sounds to Phonemes

Compare segments as bundles of properties, test minimal contrasts, and build natural classes from shared features.

1 Compare sounds2 Test a contrast3 Build a class4 Question the model
Learning objectives
  • Represent speech segments as feature bundles.
  • Use minimal pairs as evidence for contrast.
  • Identify natural classes through shared features.
  • Recognize that feature systems are analytical models.
Step 1

Compare two segments

Changing one property can create a close contrast; crossing segment types changes the relevant representation.

Step 2

Use a minimal pair as evidence

If two forms differ in one sound and have different meanings, the contrast can distinguish words in that language.

Does a written letter establish a phonemic contrast?

No. Minimal-pair reasoning concerns differences in pronunciation and meaning. Spelling can obscure or exaggerate sound contrasts.

Step 4

Question the representation

An inventory and feature system summarize an analysis; they do not replace acoustic data or language-specific evidence.

Scope

This module uses a compact English-oriented teaching inventory and broad feature labels. Actual inventories, allophony, transcription conventions, and theoretical feature systems vary across languages and analyses.

Exit question

What evidence supports calling two sounds separate phonemes?

Use a minimal pair and one feature comparison, then identify one limitation of the evidence.
