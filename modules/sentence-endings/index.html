Where does a sentence end?

Choose the rules. Change their order. See exactly which words your classifier marks as end of sentence (EOS).

Start with the period rule below. Why does it make mistakes on “Dr.” and “etc.”? Add an exception, then experiment with where it belongs.

1. Choose your rules

Select any combination, including none. New rules go to the end of the list.

2. Arrange the order

First matching rule wins. A “yes” returns that rule’s label and stops. A “no” continues down the list.

    If no rule matches → not EOS

    The abbreviation rule is a not EOS exception. An earlier EOS rule can prevent this exception from being reached.

    3. Watch the predictions

    Write one excerpt per line. Insert | after each true sentence-ending word. These markers supply the reference labels; the classifier never uses them as features.

    Example: Dr. Lee arrived. | We waved. | marks “arrived.” and “waved.” as EOS. Leave a fragment unmarked if it has no true sentence boundary. Unmarked words receive “not EOS” reference labels.

    How this classifier works

    Each whitespace-separated word, with its attached punctuation, is one example. Closing quotes and brackets do not hide terminal punctuation. Decimal points inside numbers are not terminal periods. The list of known abbreviations is .

    The reference labels come from the supplied examples or your | markers. Rule selection and order are chosen by you; this activity does not automatically train a model. An ordered rule list is a simple chain of yes/no decisions.

    Moving two EOS rules past each other may change the explanation without changing the predicted label. Moving a not EOS exception past an EOS rule can change the label.

    “No following word” is a heuristic. The last word of an excerpt is not necessarily the end of a complete sentence: see “Because I was” in the challenge set. The challenge labels use the intended complete-sentence reading.

    Precision: correct EOS predictions ÷ all EOS predictions. Recall: correct EOS predictions ÷ all true EOS words. A dash means the denominator is zero. Every word also has a correct/incorrect status when you inspect it; neutral words are correctly predicted as not EOS.
