How a Language Model Learns

Build a model from counts, then test where its knowledge ends.

Learning objectives
  • Estimate conditional probabilities from counts.
  • Explain how context creates both information and sparsity.
  • Describe what smoothing changes.
  • Distinguish statistical fit from linguistic competence.

Try it: does more context always help?

Enter “the student”. Compare the three model orders. Which model makes the narrowest prediction, and which one has the most evidence?

Interpretation: More context can make a prediction more specific, but it also leaves fewer matching observations. A longer context is not automatically a better estimate.

Step 3

Confront missing data

A zero count does not necessarily mean an impossible sentence.

Suggested experiment

Choose the trigram model and enter “the careful professor”. Turn smoothing off and on. This sequence is plausible, but the small corpus may never have observed it.

What did smoothing claim?

Smoothing did not discover a linguistic rule. It redistributed probability so unseen events were no longer treated as impossible.

Tradeoff: Giving probability to unseen events requires taking some probability away from observed events.
