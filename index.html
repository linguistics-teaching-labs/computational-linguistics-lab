CL Computational Linguistics Lab

Open teaching modules

Explore how computers learn patterns in language.

Short, guided demonstrations for introductory computational linguistics. Everything runs locally in the browser—no account, installation, or programming required.

10 standalone activities

Built to be extended

Each demonstration is a self-contained module with editable teaching text and data. Instructors can fork the repository, revise an activity, or add a new module without maintaining a server.

Created by Desen Lin and Wei Lai as an open instructional project.

Designed for instruction and exploratory research. Results use simplified methods and teaching data and should not be treated as production analysis or evidence for consequential decisions.
